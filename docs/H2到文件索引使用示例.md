# H2 到文件索引使用示例

## 概述

本文档展示如何使用字段映射配置实现 H2 数据库到文件索引的完整流程。

## 场景说明

- **源数据库**: H2 内存数据库
- **源表**: `sample_data`
- **索引类型**: 文件索引（JSON）
- **使用配置**: `field-mapping.yml`

## 完整流程

### 1. 配置字段映射

**文件**: `src/main/resources/field-mapping.yml`

```yaml
# 源表字段映射配置
source-mappings:
  sample_data:
    fields:
      - name: id
        type: LONG
        alias: id
        is-key: true
        required: true
        order: 1
      
      - name: name
        type: STRING
        alias: name
        required: true
        order: 2
      
      - name: description
        type: STRING
        alias: description
        order: 3
      
      - name: status
        type: STRING
        alias: status
        order: 4
      
      - name: created_at
        type: TIMESTAMP
        alias: created_at
        order: 5
      
      - name: updated_at
        type: TIMESTAMP
        alias: updated_at
        order: 6
    
    joins: []

# 索引字段映射配置
index-mappings:
  sample_file_index:
    source-table: sample_data
    fields:
      - name: id
        type: keyword
        source-field: id
        order: 1
      
      - name: name
        type: text
        source-field: name
        searchable: true
        order: 2
      
      - name: description
        type: text
        source-field: description
        searchable: true
        order: 3
      
      - name: status
        type: keyword
        source-field: status
        searchable: true
        order: 4
      
      - name: created_at
        type: date
        source-field: created_at
        format: "yyyy-MM-dd HH:mm:ss"
        order: 5
      
      - name: updated_at
        type: date
        source-field: updated_at
        format: "yyyy-MM-dd HH:mm:ss"
        order: 6
```

### 2. 配置 H2 环境

**文件**: `src/main/resources/application-h2.yml`

```yaml
# H2 数据库配置
spring:
  datasource:
    url: jdbc:h2:mem:testdb;MODE=MySQL;DATABASE_TO_LOWER=TRUE
    username: sa
    password: 
    driver-class-name: org.h2.Driver

# 索引配置
index:
  dataSource:
    type: h2
    table: sample_data
    timeColumn: updated_at
  
  indexTarget:
    type: file
    path: ./output
    fileName: index-output.json
  
  parallelism:
    chunkSize: 100
    threads: 2
```

### 3. 初始化数据

**文件**: `src/main/resources/init-h2.sql`

```sql
-- 创建测试表
CREATE TABLE IF NOT EXISTS sample_data (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    status VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 插入测试数据
INSERT INTO sample_data (name, description, status) VALUES
('Product A', 'Description for Product A', 'ACTIVE'),
('Product B', 'Description for Product B', 'INACTIVE'),
('Product C', 'Description for Product C', 'ACTIVE');
```

### 4. 运行索引任务

#### **启动应用**

```bash
# 使用 H2 profile 启动
java -jar target/index-0.1.0-SNAPSHOT.jar --spring.profiles.active=h2
```

#### **执行全量索引**

应用启动后，系统会：

1. **加载字段映射配置**
   ```
   ========================================
   初始化字段映射配置...
   加载了 1 个源表配置
   加载了 1 个索引配置
     - 源表 sample_data: 6 个字段, 0 个关联
     - 索引 sample_file_index: 6 个字段
   字段映射配置初始化完成
   ========================================
   ```

2. **创建分页读取器**
   ```
   ========================================
   创建分页读取器:
     表名: sample_data
     字段数: 6
     关联数: 0
     排序键: id
   ========================================
   ```

3. **生成动态 SQL**
   ```sql
   SELECT sample_data.id AS id, 
          sample_data.name AS name, 
          sample_data.description AS description, 
          sample_data.status AS status, 
          sample_data.created_at AS created_at, 
          sample_data.updated_at AS updated_at 
   FROM sample_data 
   ORDER BY sample_data.id
   ```

4. **读取数据**
   - 使用 `RdbFullReader` 读取 H2 数据
   - 自动映射字段到 `SourceRecord`

5. **写入文件**
   - 使用 `IndexFileWriter` 写入文件
   - 输出到 `./output/index-output-{timestamp}.json`

### 6. 执行增量索引

**触发增量索引**（每5分钟自动执行）：

1. **创建增量读取器**
   ```
   ========================================
   创建增量读取器（时间范围）:
     表名: sample_data
     时间范围: 2025-01-16 12:25:00 ~ 2025-01-16 12:30:00
     重叠窗口: 5 分钟
     生成的 SQL: SELECT ... WHERE updated_at BETWEEN ? AND ?
   ========================================
   ```

2. **读取增量数据**
   - 读取时间窗口内的变更数据
   - 自动映射到 `SourceRecord`

3. **追加到文件**
   - 增量数据追加写入

## 核心组件工作流程

```
field-mapping.yml
    ↓
FieldMappingService (加载配置)
    ↓
RdbFullReader (获取字段配置)
    ↓
DynamicSqlBuilder (生成 SQL)
    ↓
SELECT sample_data.id AS id, ...
FROM sample_data
ORDER BY sample_data.id
    ↓
DynamicSourceRecordRowMapper (映射数据)
    ↓
SourceRecord {
  id: "1",
  data: {id: 1, name: "Product A", ...}
}
    ↓
IndexFileWriter (写入文件)
    ↓
./output/index-output-{timestamp}.json
```

## 动态 SQL 生成示例

### 场景 1: 简单查询

**配置**:
```yaml
source-mappings:
  sample_data:
    fields:
      - name: id
        type: LONG
        is-key: true
      - name: name
        type: STRING
```

**生成的 SQL**:
```sql
SELECT sample_data.id, sample_data.name 
FROM sample_data 
ORDER BY sample_data.id
```

### 场景 2: 带别名

**配置**:
```yaml
source-mappings:
  sample_data:
    fields:
      - name: id
        type: LONG
        alias: product_id
        is-key: true
      - name: name
        type: STRING
        alias: product_name
```

**生成的 SQL**:
```sql
SELECT sample_data.id AS product_id, 
       sample_data.name AS product_name 
FROM sample_data 
ORDER BY sample_data.id
```

### 场景 3: 带关联表

**配置**:
```yaml
source-mappings:
  orders:
    fields:
      - name: id
        type: LONG
        is-key: true
      - name: user_id
        type: LONG
    joins:
      - table: users
        on-field: user_id
        type: LEFT
        fields:
          - name: name
            type: STRING
            alias: user_name
```

**生成的 SQL**:
```sql
SELECT orders.id, 
       orders.user_id, 
       users.name AS user_name 
FROM orders 
LEFT JOIN users ON orders.user_id = users.id 
ORDER BY orders.id
```

## 常见问题

### Q1: 如何添加新字段？

**答**: 只需在 `field-mapping.yml` 中添加字段配置，无需修改代码。

```yaml
fields:
  - name: new_field
    type: STRING
    alias: new_field
    order: 7
```

### Q2: 如何关联其他表？

**答**: 在 `joins` 部分添加关联配置。

```yaml
joins:
  - table: user_profile
    on-field: user_id
    type: LEFT
    fields:
      - name: phone
        alias: user_phone
```

### Q3: 如何自定义字段转换？

**答**: 使用 `transform` 属性。

```yaml
fields:
  - name: full_name
    type: STRING
    transform: "CONCAT(first_name, ' ', last_name)"
```

分步任务说明
## 目的与范围

本文件基于《需求说明》《架构设计说明》《项目结构说明》，输出可执行的分步实施任务清单，覆盖环境搭建、功能实现、扩容与调度、可观测性与运维。每个任务包含目标、主要工作、产出与完成标准（Done）。

## 阶段 0：环境与项目骨架

1) 初始化工程与依赖
   - 工作：创建 Spring Boot + Spring Batch 工程；配置 Java 17；引入 JDBC、ES/GetQuick 客户端、Quartz、Micrometer 依赖。
   - 产出：Maven/Gradle 脚本、Application 启动类、基础包结构。
   - Done：应用可启动；/actuator/health 正常。

2) 配置管理与多环境
   - 工作：创建 application-{dev,test,prod}.yml；区分数据源、索引目标、并行度、Cron。
   - 产出：配置文件与示例密钥管理方案。
   - Done：依据 Profile 切换配置生效。

## 阶段 1：数据源与索引目标适配

3) 数据源 Reader 实现（RDB/文件）
   - 工作：实现 RdbFullReader（分页/游标）、RdbDeltaReader（时间窗口/变更表）、CSV/JSON Reader。
   - 产出：`app/batch/reader/*` 与标准模型 `SourceRecord`。
   - Done：本地数据源联通；小样本读取通过。

4) 索引 Writer 实现（ES/GetQuick/文件）
   - 工作：实现 ElasticsearchWriter、GetQuickWriter、可选 FileIndexWriter；支持批量写、Upsert、删除。
   - 产出：`app/batch/writer/*` 与 `IndexDocument` 模型。
   - Done：对接目标索引联通；小样本写入/更新/删除通过。

## 阶段 2：全量/增量 Job 实现

5) 全量索引 Job
   - 工作：FullIndexJobConfig 定义 Steps（清理/读取处理写入/检查/切换）；参数化 chunkSize、并行度。
   - 产出：`FullIndexJobConfig.java`、`JobCompletionListener.java`。
   - Done：开发环境可运行全量并完成别名切换或等效机制。

6) 增量索引 Job
   - 工作：增量读取（新增/修改/删除），处理与写入；迟到数据重叠窗口；失败阈值触发重建策略。
   - 产出：`IncrementalIndexJobConfig.java`、窗口与位点管理实现。
   - Done：5 分钟窗口内端到端完成一次增量周期（样本）。

## 阶段 3：完整性检查与恢复

7) 完整性检查服务
   - 工作：IndexCheckService 指标（总量、校验和、采样查询、错误率阈值）；CheckMetrics 数据模型。
   - 产出：`app/batch/check/*`。
   - Done：可配置检查项，失败准确告警。

8) 重试与重建策略
   - 工作：IndexRetryService（指数退避、最大次数）；增量失败阈值触发局部/全量重建；全量失败回滚别名。
   - 产出：`app/batch/retry/*` 与策略配置。
   - Done：故障注入测试通过（网络抖动、限流、数据异常）。

## 阶段 4：调度与触发

9) Quartz 集群调度
   - 工作：QuartzConfig、JobDetail/Trigger、JDBC JobStore；Misfire 策略；统一时区。
   - 产出：`app/scheduler/quartz/*`、`quartz.properties`。
   - Done：多实例仅一处触发；故障转移可用；Cron 可按需调整。

10) Kubernetes CronJob（可选）
   - 工作：编写 CronJob 清单；并发策略 Forbid/Replace；backoffLimit；应用侧分布式锁（DB/Redis）。
   - 产出：部署清单、`DistributedLockService.java`、`K8sCronNotes.md`。
   - Done：同一时间仅一个实例执行；失败按策略重试。

11) API 动态触发与查询
   - 工作：JobTriggerController、JobLauncherService；入参校验与映射；任务状态查询。
   - 产出：`app/api/controller/*`、`dto/*`。
   - Done：可通过 REST 启动全量/增量并查询状态。

## 阶段 5：扩容与性能优化

12) 单实例并行
   - 工作：多线程 Step（TaskExecutor）、chunkSize/commitInterval 调优；批量写大小与连接池。
   - 产出：并行与批量参数模板。
   - Done：吞吐达标且错误率受控。

13) 分片并行（本地/远程）
   - 工作：RangePartitioner、HashPartitioner、RemotePartitionConfig；稳定哈希；动态负载均衡。
   - 产出：`app/batch/partition/*` 与运行样例。
   - Done：分片线性扩展接近预期；热点受控。

14) 多节点与互斥
   - 工作：Quartz 集群验证互斥；K8s 场景验证分布式锁；Writer 幂等与重复执行无副作用。
   - 产出：互斥验证报告与回归用例。
   - Done：并发/重启/漂移场景无重复执行与脏写。

## 阶段 6：可观测性与安全

15) 指标与日志
   - 工作：Micrometer 指标（吞吐、延迟、错误率、分片耗时）、结构化日志（jobId、step、partitionId、traceId）。
   - 产出：MetricsConfig、Grafana 看板模板、日志字段规范。
   - Done：告警阈值与仪表盘齐全，定位问题 < 10 分钟。

16) 安全与审计
   - 工作：API 鉴权（OAuth2/JWT/反向代理）、最小权限账号、任务触发与结果审计。
   - 产出：SecurityConfig、审计日志方案。
   - Done：未授权访问被拒；审计可追溯。

## 阶段 7：运维与交付

17) 部署与回滚
   - 工作：容器镜像、Helm/K8s 清单或主机部署脚本；蓝绿/滚动发布；配置中心接入（可选）。
   - 产出：部署清单与回滚步骤、变更记录模板。
   - Done：演练通过；变更窗口内可回滚。

18) SOP 与故障手册
   - 工作：常见失败类型与处置流程（数据源不可达、目标限流、索引检查失败、磁盘/CPU 瓶颈）。
   - 产出：SOP 文档、应急联系方式与值班表模板。
   - Done：演练通过；平均恢复时间（MTTR）达标。

## 里程碑与验收

- 里程碑 M1（最小可用）：
  - 增量 Job 跑通（RDB→ES），Quartz 单机调度，基本检查，API 触发
  - 验收：小样本端到端通过；指标与日志可见

- 里程碑 M2（扩容与高可用）：
  - 多线程 + 本地分片；Quartz 集群或 K8s CronJob + 分布式锁
  - 验收：并发场景无重复执行；吞吐提升达成目标

- 里程碑 M3（弹性与稳定）：
  - 远程分片、多实例水平扩展；重试与重建完善；看板与告警
  - 验收：大数据量压测通过；故障注入回归通过

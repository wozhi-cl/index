# 动态记录系统说明

## 概述

本系统使用配置文件驱动的动态记录模型，替代了原有的固定字段 `SourceRecord` 和 `IndexDocument`。所有字段定义都通过 `field-mapping.yml` 配置文件管理，实现了真正的配置驱动架构。

---

## 核心组件

### 1. **DynamicRecord** - 动态数据记录

**位置**: `src/main/java/com/company/index/common/model/DynamicRecord.java`

**功能**: 
- 统一的动态数据模型，替代 `SourceRecord` 和 `IndexDocument`
- 支持任意字段结构，完全由配置文件驱动
- 包含记录类型（SOURCE/INDEX）和操作类型（INSERT/UPDATE/DELETE）

**主要方法**:
```java
// 创建源记录
DynamicRecord sourceRecord = DynamicRecord.createSourceRecord("orders");

// 设置字段
sourceRecord.setField("order_id", 1L);
sourceRecord.setField("order_no", "ORD001");

// 获取字段
Long orderId = sourceRecord.getField("order_id", Long.class);

// 转换为索引记录
DynamicRecord indexRecord = sourceRecord.toIndexRecord("order_index");
```

**字段结构**:
```
DynamicRecord
├── recordType: SOURCE | INDEX
├── tableName: 表名或索引名
├── operation: INSERT | UPDATE | DELETE
├── timestamp: 时间戳
├── source: 数据来源
├── version: 版本号
├── fields: Map<String, Object>      # 动态字段数据
└── fieldTypes: Map<String, String>  # 字段类型映射
```

### 2. **RecordBuilderService** - 记录构建服务

**位置**: `src/main/java/com/company/index/common/service/RecordBuilderService.java`

**功能**:
- 从 `ResultSet` 构建源记录
- 从源记录转换为索引记录（根据索引字段映射）
- 将动态记录转换为 Map（用于写入）
- 验证记录字段完整性

**使用示例**:
```java
// 从 ResultSet 构建源记录
DynamicRecord sourceRecord = recordBuilderService.buildSourceRecordFromResultSet(rs, "orders");

// 转换为索引记录
DynamicRecord indexRecord = recordBuilderService.convertToIndexRecord(sourceRecord, "order_index");

// 转换为 Map（用于写入 Elasticsearch/File）
Map<String, Object> data = recordBuilderService.convertRecordToMap(indexRecord);

// 验证记录
boolean isValid = recordBuilderService.validateRecord(sourceRecord, "orders");
```

### 3. **DynamicRdbFullReader** - 动态全量读取器

**位置**: `src/main/java/com/company/index/batch/reader/DynamicRdbFullReader.java`

**功能**:
- 根据配置文件动态生成 SQL
- 支持分页读取和游标读取
- 自动处理 JOIN 关联
- 返回 `DynamicRecord` 对象

**使用示例**:
```java
// 创建分页读取器
JdbcPagingItemReader<DynamicRecord> reader = 
    dynamicRdbFullReader.createPagingReader(1000);

// 创建游标读取器
JdbcCursorItemReader<DynamicRecord> reader = 
    dynamicRdbFullReader.createCursorReader();
```

---

### 4. **DynamicRdbDeltaReader** - 动态增量读取器

**位置**: `src/main/java/com/company/index/batch/reader/DynamicRdbDeltaReader.java`

**功能**:
- 根据时间范围读取增量数据
- 自动处理时间重叠
- 支持 JOIN 关联

**使用示例**:
```java
LocalDateTime startTime = LocalDateTime.now().minusHours(1);
LocalDateTime endTime = LocalDateTime.now();

JdbcCursorItemReader<DynamicRecord> reader = 
    dynamicRdbDeltaReader.createDeltaReader(startTime, endTime);
```

### 5. **DynamicWriterFactory** - 动态 Writer 工厂

**位置**: `src/main/java/com/company/index/batch/writer/DynamicWriterFactory.java`

**功能**:
- 根据配置创建不同类型的 Writer
- 支持文件输出（Elasticsearch 待实现）
- 管理索引生命周期（创建、删除、完成）

**使用示例**:
```java
// 获取 Writer
ItemWriter<DynamicRecord> writer = dynamicWriterFactory.getWriter();

// 索引管理
dynamicWriterFactory.createIndexIfNotExists();
dynamicWriterFactory.deleteIndex();
dynamicWriterFactory.finishIndex();
Object stats = dynamicWriterFactory.getIndexStats();
```

### 6. **DynamicFullIndexJobConfig** - 动态全量索引 Job

**位置**: `src/main/java/com/company/index/batch/job/DynamicFullIndexJobConfig.java`

**功能**:
- 完整的全量索引流程
- 使用 `DynamicRecord` 模型
- 支持重试和错误处理

**Job 流程**:
```
dynamicCleanupStep (清理)
    ↓
dynamicReadProcessWriteStep (读取处理写入)
    ↓
dynamicFullCheckStep (检查)
    ├─ 成功 → dynamicFinishStep (完成)
    └─ 失败 → dynamicRetryDecisionStep (重试决策)
        ├─ 未达重试次数 → 回到 dynamicCleanupStep
        └─ 已达重试次数 → dynamicRebuildStep (重建)
```

---

### 7. **DynamicIncrementalIndexJobConfig** - 动态增量索引 Job

**位置**: `src/main/java/com/company/index/batch/job/DynamicIncrementalIndexJobConfig.java`

**功能**:
- 增量数据索引流程
- 使用 `DynamicRecord` 模型
- 支持时间范围查询
- 失败时自动触发全量重建

**Job 流程**:
```
dynamicDeltaReadProcessWriteStep (读取增量数据)
    ↓
dynamicIncrementalCheckStep (检查)
    ├─ 成功 → dynamicIncrementalFinishStep (完成)
    └─ 失败 → dynamicTriggerFullRebuildStep (触发全量重建)
```

**使用示例**:
```java
// 启动增量索引 Job
JobParameters params = new JobParametersBuilder()
    .addLong("timestamp", System.currentTimeMillis())
    .addString("startTime", "2025-10-16T10:00:00")
    .addString("endTime", "2025-10-16T11:00:00")
    .toJobParameters();

jobLauncher.run(dynamicIncrementalIndexJob, params);
```

## 配置文件

### field-mapping.yml

**位置**: `src/main/resources/field-mapping.yml`

**结构**:
```yaml
source-mappings:
  orders:                    # 源表名
    fields:                  # 主表字段
      - name: id
        type: LONG
        alias: order_id
        is-key: true
        required: true
        order: 1
    
    joins:                   # 关联表
      - table: users
        on-field: user_id
        type: LEFT
        fields:
          - name: name
            alias: user_name
            order: 6

index-mappings:
  order_index:               # 索引名
    source-table: orders     # 源表
    fields:                  # 索引字段
      - name: order_id
        type: keyword
        source-field: order_id
        searchable: false
        sortable: true
```

## 数据流

### 全量索引流程

```
1. 配置加载
   field-mapping.yml → FieldMappingService

2. SQL 生成
   FieldMappingService → DynamicSqlBuilder → 完整 SQL

3. 数据读取
   SQL → Database → ResultSet → DynamicRecord (SOURCE)

4. 数据处理
   DynamicRecord (SOURCE) → RecordBuilderService → DynamicRecord (INDEX)

5. 数据写入
   DynamicRecord (INDEX) → RecordBuilderService → Map → Writer
```

### 字段映射流程

```
源表 orders:
  id → order_id
  order_no → order_no
  amount → amount
  users.name → user_name (JOIN)
  users.phone → user_phone (JOIN)

索引 order_index:
  order_id ← order_id
  order_no ← order_no
  amount ← amount
  user_name ← user_name
  user_phone ← user_phone
```

## 新旧对比

### 旧方式（固定字段）

**SourceRecord.java**:
```java
public class SourceRecord {
    private String id;
    private String type;
    private LocalDateTime timestamp;
    private Map<String, Object> data;  // 所有业务字段
    private String source;
    private Long version;
}
```

**问题**:
- 字段结构固定
- 无法表达字段类型
- 无法区分源数据和索引数据
- 字段映射在代码中硬编码

### 新方式（动态字段）

**DynamicRecord.java**:
```java
public class DynamicRecord {
    private RecordType recordType;           // SOURCE | INDEX
    private String tableName;                // 表名或索引名
    private OperationType operation;         // INSERT | UPDATE | DELETE
    private LocalDateTime timestamp;
    private String source;
    private Long version;
    
    private Map<String, Object> fields;      // 动态字段
    private Map<String, String> fieldTypes;  // 字段类型
}
```

**优势**:
- ✅ 字段完全动态，由配置驱动
- ✅ 包含字段类型信息
- ✅ 区分源数据和索引数据
- ✅ 字段映射在配置文件中
- ✅ 支持字段别名和转换
- ✅ 支持 JOIN 关联

## 使用场景

### 场景 1: H2 订单表 → 文件索引

**配置**:
```yaml
# application-h2.yml
index:
  dataSource:
    type: h2
    table: orders
  indexTarget:
    type: file
    indexName: order_index
```

**执行**:
```java
// 启动 Job
jobLauncher.run(dynamicFullIndexJob, jobParameters);
```

```json
  "_timestamp": "2025-10-16T10:30:00",
  "_source": "RDB:orders",
  "_version": 1
}
```

**只需修改配置**:
```yaml

source-mappings:
  orders:
    fields:
      # ... 现有字段
      - name: created_at    # 新增字段
        type: TIMESTAMP
        alias: created_at
        order: 6

index-mappings:
  order_index:
    fields:
      # ... 现有字段
      - name: created_date  # 新增索引字段
        type: date
        source-field: created_at
        format: "yyyy-MM-dd"
        order: 7
```

**无需修改代码！**

### 场景 3: 添加新的 JOIN

**只需修改配置**:
```yaml
source-mappings:
  orders:
    joins:
      # ... 现有 JOIN

        on-field: product_id
        type: LEFT
        fields:
          - name: name
            alias: product_name
          - name: price
            alias: product_price
```

**无需修改代码！**

## 快速开始

### 1. 配置字段映射

编辑 `src/main/resources/field-mapping.yml`:
```yaml
source-mappings:
  your_table:
    fields:
      - name: id
        type: LONG
        is-key: true
    joins: []

index-mappings:
  your_index:
    source-table: your_table
    fields:
      - name: id
        type: keyword
        source-field: id
```

### 2. 配置数据源

编辑 `application-h2.yml`:
```yaml
index:
  dataSource:
    table: your_table
  indexTarget:
    indexName: your_index
```

### 3. 运行 Job

```java
@Autowired
private Job dynamicFullIndexJob;

@Autowired
private JobLauncher jobLauncher;

JobParameters params = new JobParametersBuilder()
    .addLong("timestamp", System.currentTimeMillis())
    .toJobParameters();

jobLauncher.run(dynamicFullIndexJob, params);
```

完成！系统会自动根据配置生成 SQL、读取数据、转换字段、写入索引。

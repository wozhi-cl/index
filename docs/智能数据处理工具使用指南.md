# 智能数据处理工具使用指南

## 📋 概述

针对字段非常多（100+字段）的 model，手动处理每个字段会非常繁琐。本项目提供了一套智能工具，可以自动处理大部分字段，只需要针对特殊字段进行特殊处理。

## 🛠️ 工具清单

1. **GenericRowMapper** - 通用行映射器，自动将数据库记录映射到 Java 对象
2. **SqlBuilder** - SQL 构建器，智能生成复杂的 SQL 查询
3. **TestDataGenerator** - 测试数据生成器，自动生成测试数据和 SQL

## 📖 使用示例

### 示例场景

假设我们有两个表需要 JOIN 查询：
- `USER_INFO` 表：包含 100+ 个用户字段
- `USER_DETAIL` 表：包含 50+ 个用户详情字段

需要将它们合并到 `SourceRecord` 或 `IndexDocument` 中。

### 1. GenericRowMapper 使用示例

#### 基础用法（自动映射所有字段）

```java
import com.company.index.common.util.GenericRowMapper;
import com.company.index.common.model.SourceRecord;

// 创建通用 RowMapper
GenericRowMapper<SourceRecord> rowMapper = new GenericRowMapper.Builder<>(SourceRecord.class)
    .autoUnderscoreToCamelCase(true)  // 自动转换下划线为驼峰
    .build();

// 使用 JdbcTemplate 查询
List<SourceRecord> records = jdbcTemplate.query(sql, rowMapper);
```

#### 高级用法（处理特殊字段）

```java
// 创建带特殊处理的 RowMapper
GenericRowMapper<SourceRecord> rowMapper = new GenericRowMapper.Builder<>(SourceRecord.class)
    .autoUnderscoreToCamelCase(true)
    
    // 处理 CLOB 字段
    .addClobHandler("LARGE_TEXT_FIELD")
    
    // 处理日期时间字段
    .addDateTimeHandler("CREATED_TIME")
    .addDateTimeHandler("UPDATED_TIME")
    
    // 自定义字段处理器
    .addSpecialHandler("COMPLEX_FIELD", (rs, name) -> {
        // 自定义逻辑
        String rawValue = rs.getString(name);
        return processComplexField(rawValue);
    })
    
    // 字段名映射（数据库字段 -> Java字段）
    .addFieldMapping("USER_ID", "id")
    .addFieldMapping("USER_NAME", "name")
    
    .build();
```

### 2. SqlBuilder 使用示例

#### 简单 SELECT 查询

```java
import com.company.index.common.util.SqlBuilder;

String sql = SqlBuilder.create()
    .from("USER_INFO", "u")
    .selectAll("u")
    .where("u.STATUS = 'ACTIVE'")
    .orderBy("u.CREATED_AT DESC")
    .build();

// 生成的 SQL:
// SELECT u.*
// FROM USER_INFO u
// WHERE u.STATUS = 'ACTIVE'
// ORDER BY u.CREATED_AT DESC
```

#### 复杂 JOIN 查询

```java
// 两表 JOIN
String sql = SqlBuilder.create()
    .from("USER_INFO", "u")
    .leftJoin("USER_DETAIL", "d", "u.USER_ID = d.USER_ID")
    
    // 从 USER_INFO 选择字段
    .selectFields("u", 
        "USER_ID", "USER_NAME", "EMAIL", "PHONE", 
        "STATUS", "CREATED_AT", "UPDATED_AT")
    
    // 从 USER_DETAIL 选择字段（带前缀避免冲突）
    .selectFieldsWithPrefix("d",
        "ADDRESS", "CITY", "PROVINCE", "ZIP_CODE",
        "COMPANY", "DEPARTMENT", "POSITION")
    
    .where("u.STATUS = 'ACTIVE'")
    .and("u.CREATED_AT > CURRENT_TIMESTAMP - INTERVAL 7 DAY")
    .orderBy("u.CREATED_AT DESC")
    .build();

// 生成的 SQL:
// SELECT u.USER_ID, u.USER_NAME, u.EMAIL, u.PHONE, u.STATUS, u.CREATED_AT, u.UPDATED_AT,
//        d.ADDRESS AS d_ADDRESS, d.CITY AS d_CITY, d.PROVINCE AS d_PROVINCE, ...
// FROM USER_INFO u
// LEFT JOIN USER_DETAIL d ON u.USER_ID = d.USER_ID
// WHERE u.STATUS = 'ACTIVE' AND u.CREATED_AT > CURRENT_TIMESTAMP - INTERVAL 7 DAY
// ORDER BY u.CREATED_AT DESC
```

#### 使用便捷方法

```java
// 两表 JOIN 的便捷方法
String sql = SqlBuilder.twoTableJoin(
    "USER_INFO", "u",
    "USER_DETAIL", "d",
    "u.USER_ID = d.USER_ID",
    new String[]{"USER_ID", "USER_NAME", "EMAIL"},  // 表1字段
    new String[]{"ADDRESS", "CITY", "COMPANY"}      // 表2字段
);
```

### 3. TestDataGenerator 使用示例

#### 生成测试对象

```java
import com.company.index.common.util.TestDataGenerator;
import com.company.index.common.model.SourceRecord;

// 创建测试数据生成器
TestDataGenerator generator = TestDataGenerator.forClass(SourceRecord.class)
    .excludeField("id")  // 排除 ID（数据库自动生成）
    
    // 自定义特定字段的生成逻辑
    .withCustomGenerator("status", () -> "ACTIVE")
    .withCustomGenerator("email", () -> "test" + System.currentTimeMillis() + "@test.com")
    
    .build();

// 生成单个测试对象
SourceRecord record = generator.generateOne();

// 生成多个测试对象
List<SourceRecord> records = generator.generateList(100);
```

#### 生成 SQL INSERT 语句

```java
// 生成单条 INSERT 语句
String insertSql = generator.generateInsertSql("USER_INFO");
System.out.println(insertSql);
// INSERT INTO USER_INFO (USER_NAME, EMAIL, PHONE, STATUS, ...) VALUES ('张明', 'user123@example.com', '13812345678', 'ACTIVE', ...)

// 批量生成 INSERT 语句
List<String> insertSqlList = generator.generateInsertSqlList("USER_INFO", 100);

// 写入文件
Files.write(Paths.get("test-data.sql"), insertSqlList);
```

## 🔧 实际应用示例

### 完整示例：处理 100+ 字段的表

假设您有以下 model：

```java
public class UserSourceRecord {
    // 用户基础信息（来自 USER_INFO 表）
    private Long userId;
    private String userName;
    private String email;
    // ... 100+ 个字段
    
    // 用户详情（来自 USER_DETAIL 表）
    private String address;
    private String company;
    // ... 50+ 个字段
    
    private LocalDateTime timestamp;
    private Map<String, Object> data;
    // Getters and Setters
}
```

#### 步骤 1: 构建 SQL

```java
@Component
public class UserDataReader {
    
    private String buildJoinSql() {
        return SqlBuilder.create()
            .from("USER_INFO", "u")
            .leftJoin("USER_DETAIL", "d", "u.USER_ID = d.USER_ID")
            
            // 选择所有需要的字段（自动处理）
            .selectFields("u",
                // 只列出必要的字段，其他字段自动处理
                "USER_ID", "USER_NAME", "EMAIL", "PHONE",
                "STATUS", "CREATED_AT", "UPDATED_AT"
                // ... 其他字段
            )
            
            .selectFieldsWithPrefix("d",
                // 详情表字段，自动添加前缀避免冲突
                "ADDRESS", "CITY", "PROVINCE", "COMPANY"
                // ... 其他字段
            )
            
            .where("u.STATUS = 'ACTIVE'")
            .orderBy("u.UPDATED_AT DESC")
            .build();
    }
}
```

#### 步骤 2: 创建 RowMapper

```java
@Component
public class UserDataReader {
    
    private GenericRowMapper<UserSourceRecord> createRowMapper() {
        return new GenericRowMapper.Builder<>(UserSourceRecord.class)
            .autoUnderscoreToCamelCase(true)
            
            // 只处理特殊字段
            .addDateTimeHandler("CREATED_AT")
            .addDateTimeHandler("UPDATED_AT")
            .addClobHandler("LARGE_DESCRIPTION")
            
            // 字段名映射（如果需要）
            .addFieldMapping("USER_ID", "userId")
            .addFieldMapping("USER_NAME", "userName")
            
            // 特殊处理：将所有原始数据放入 data Map
            .addSpecialHandler("data", (rs, name) -> {
                Map<String, Object> dataMap = new HashMap<>();
                ResultSetMetaData metaData = rs.getMetaData();
                for (int i = 1; i <= metaData.getColumnCount(); i++) {
                    dataMap.put(metaData.getColumnName(i), rs.getObject(i));
                }
                return dataMap;
            })
            
            .build();
    }
    
    public List<UserSourceRecord> readData() {
        String sql = buildJoinSql();
        GenericRowMapper<UserSourceRecord> rowMapper = createRowMapper();
        
        return jdbcTemplate.query(sql, rowMapper);
    }
}
```

#### 步骤 3: 生成测试数据

```java
@Test
public void generateTestData() {
    TestDataGenerator generator = TestDataGenerator.forClass(UserSourceRecord.class)
        .excludeField("userId")  // ID 由数据库生成

    // 写入文件或直接执行
    insertSqls.forEach(sql -> jdbcTemplate.execute(sql));
}
```

## 🎯 最佳实践

### 1. 字段命名约定

- **数据库**: 使用大写下划线命名（USER_NAME, CREATED_AT）
- **Java**: 使用驼峰命名（userName, createdAt）
- **工具会自动转换**

### 2. 特殊字段处理

只为以下字段添加特殊处理器：

```java
- CLOB/TEXT 类型 -> addClobHandler()
- TIMESTAMP 类型 -> addDateTimeHandler()
- JSON 字符串 -> addSpecialHandler() 自定义解析
- 枚举类型 -> addSpecialHandler() 自定义转换
- 复杂计算字段 -> addSpecialHandler() 自定义逻辑
```

### 3. SQL 构建技巧

```java
// 批量选择字段
String[] fields = {
    "FIELD1", "FIELD2", "FIELD3", // ...
    "FIELD98", "FIELD99", "FIELD100"
};
builder.selectFields("t1", fields);

// 或从配置文件读取
Properties config = loadConfig();
String[] fields = config.getProperty("select.fields").split(",");
builder.selectFields("t1", fields);
```

### 4. 测试数据生成技巧

```java
// 为不同环境生成不同数据
if (environment.equals("dev")) {
    generator.withCustomGenerator("status", () -> "ACTIVE");
} else if (environment.equals("test")) {
    generator.withCustomGenerator("status", () -> randomStatus());
}

// 生成关联数据
List<Long> userIds = generateUserIds();
int index = 0;
generator.withCustomGenerator("userId", () -> userIds.get(index++));
```

## 🔍 故障排查

### 问题 1: 字段映射失败

**原因**: 字段名不匹配

**解决**:
```java
// 启用调试日志查看映射过程
.addSpecialHandler("debug", (rs, name) -> {
    System.out.println("Mapping field: " + name);
    return null;
})

// 或添加显式映射
.addFieldMapping("DB_FIELD_NAME", "javaFieldName")
```

### 问题 2: 类型转换错误

**原因**: 数据库类型与 Java 类型不匹配

**解决**:
```java
.addSpecialHandler("problematicField", (rs, name) -> {
    try {
        return rs.getObject(name, TargetType.class);
    } catch (Exception e) {
        // 返回默认值或处理异常
        return defaultValue;
    }
})
```

### 问题 3: 性能问题

**原因**: 反射操作较慢

**解决**:
```java
// 1. 缓存 RowMapper 实例
@Bean
public GenericRowMapper<UserSourceRecord> userRowMapper() {
    return new GenericRowMapper.Builder<>(UserSourceRecord.class)
        .autoUnderscoreToCamelCase(true)
        .build();
}

// 2. 只选择需要的字段，不要 SELECT *
SqlBuilder.create()
    .selectFields("t", "FIELD1", "FIELD2")  // 明确指定
    .from("TABLE", "t")
```

## 📚 API 参考

### GenericRowMapper.Builder

| 方法 | 说明 |
|------|------|
| `autoUnderscoreToCamelCase(boolean)` | 启用/禁用自动下划线转驼峰 |
| `addFieldMapping(String, String)` | 添加字段名映射 |
| `addSpecialHandler(String, BiFunction)` | 添加特殊字段处理器 |
| `addDateTimeHandler(String)` | 添加日期时间处理器 |
| `addClobHandler(String)` | 添加 CLOB 处理器 |

### SqlBuilder

| 方法 | 说明 |
|------|------|
| `from(String, String)` | 设置主表和别名 |
| `select(String...)` | 选择字段 |
| `selectFields(String, String...)` | 选择字段（带表别名） |
| `selectFieldsWithPrefix(String, String...)` | 选择字段并添加前缀 |
| `leftJoin(String, String, String)` | LEFT JOIN |
| `innerJoin(String, String, String)` | INNER JOIN |
| `where(String)` | WHERE 条件 |
| `orderBy(String...)` | ORDER BY |

### TestDataGenerator.Builder

| 方法 | 说明 |
|------|------|
| `withCustomGenerator(String, Supplier)` | 自定义字段生成器 |
| `excludeField(String)` | 排除字段 |
| `generateOne()` | 生成单个对象 |
| `generateList(int)` | 生成多个对象 |
| `generateInsertSql(String)` | 生成 INSERT SQL |

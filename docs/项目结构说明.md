项目结构说明
## 目的

本文件基于《需求说明》《架构设计说明》，提出推荐的项目目录结构与各模块/文件职责，便于团队统一约定与快速落地。实际代码生成后可据此微调。

## 顶层结构

```
index/
  docs/
    需求说明.md
    架构设计说明.md
    项目结构说明.md
  app/
    api/
    batch/
    common/
    config/
    scheduler/
    infrastructure/
  build/
  scripts/
```

## 模块与目录说明

### docs/
- 需求说明.md：需求边界与功能/非功能约束。
- 架构设计说明.md：技术架构、扩容与调度方案、部署与参数建议。
- 项目结构说明.md：当前文档。

### app/
业务代码主目录（Spring Boot 应用）。

#### app/api/
- controller/
  - JobTriggerController.java：提供 REST 接口触发全量/增量任务、查询任务状态。
- dto/
  - JobRequest.java：任务请求参数（时间窗口、数据源类型、索引目标、重建策略等）。
  - JobResponse.java：任务启动结果、jobInstanceId/jobExecutionId 等。
- mapper/
  - ApiMapper.java：API 与内部参数对象映射（可选）。

#### app/batch/
- job/
  - FullIndexJobConfig.java：全量索引 Job/Steps/Flow 定义。
  - IncrementalIndexJobConfig.java：增量索引 Job/Steps/Flow 定义。
  - JobCompletionListener.java：任务完成监听，输出指标与审计。
  - JobLauncherService.java：封装 Job 启动与参数构建。
- reader/
  - RdbFullReader.java：全量 RDB 读取器（分页/游标）。
  - RdbDeltaReader.java：增量 RDB 读取器（时间戳/变更表）。
  - FileCsvReader.java：CSV Reader（可复用）。
  - FileJsonReader.java：JSON Reader（可复用）。
- processor/
  - NormalizeProcessor.java：字段清洗、映射、去重等。
  - ValidationProcessor.java：数据校验，不合规数据标记为可跳过。
- writer/
  - ElasticsearchWriter.java：批量写入/Upsert/删除处理。
  - GetQuickWriter.java：对接日立 GetQuick Search 写入。
  - FileIndexWriter.java：可选文件落地 Writer。
- check/
  - IndexCheckService.java：完整性检查（总量/校验和/采样查询/阈值）。
  - CheckMetrics.java：检查指标模型与结果对象。
- retry/
  - IndexRetryService.java：重试与重建策略（指数退避、阈值触发）。
- partition/
  - RangePartitioner.java：范围分片（主键/时间段）。
  - HashPartitioner.java：哈希分片（稳定哈希）。
  - RemotePartitionConfig.java：远程分片主控与工作端配置。
- support/
  - BatchConstants.java：Chunk 大小、并行度默认值等常量。
  - ItemReaders.java / ItemWriters.java：Reader/Writer 工厂与装配。

#### app/scheduler/
- quartz/
  - QuartzConfig.java：Quartz 集群与线程池、JobDetail/Trigger 配置。
  - FullIndexTrigger.java：全量任务 Cron Trigger 定义。
  - IncrementalIndexTrigger.java：增量任务 Cron Trigger 定义。
- k8s/
  - K8sCronNotes.md：K8s CronJob 运行时约定（并发策略、backoff、资源）。
- lock/
  - DistributedLockService.java：分布式锁（DB/Redis），用于 K8s 并发互斥。

#### app/config/
- Application.java：Spring Boot 启动类。
- BatchRepositoryConfig.java：JobRepository/Explorer/TransactionManager 配置。
- DataSourceConfig.java：多数据源与连接池配置（MySQL/Oracle）。
- EsClientConfig.java：Elasticsearch 客户端装配。
- GetQuickClientConfig.java：GetQuick 客户端装配。
- MetricsConfig.java：Micrometer/Prometheus 指标导出。
- SecurityConfig.java：API 鉴权与最小权限控制（如适用）。

#### app/common/
- exception/
  - BusinessException.java：业务异常基类。
  - RetryableDataAccessException.java：可重试数据异常。
- model/
  - SourceRecord.java：源数据标准模型。
  - IndexDocument.java：索引目标标准模型。
- util/
  - TimeWindowUtil.java：时间窗口计算、迟到数据重叠窗口。
  - HashingUtil.java：稳定哈希工具。
  - JsonUtil.java：JSON 序列化工具。

#### app/infrastructure/
- repository/
  - ChangeLogRepository.java：增量变更查询。
  - CheckpointRepository.java：检查点与最大位点保存。
- dao/
  - GenericJdbcDao.java：通用 JDBC 访问封装。
- client/
  - ElasticsearchClient.java：ES 低层访问封装。
  - GetQuickClient.java：GetQuick 低层访问封装。

### build/
- gradle/或 maven/：构建脚本与插件。

### scripts/
- local-run.sh：本地启动全量/增量任务脚本。
- smoke-check.sh：冒烟检查（连通性、权限、最小数据量）。

## 配置文件建议

```
src/main/resources/
  application.yml
  application-dev.yml
  application-test.yml
  application-prod.yml
  quartz.properties                # Quartz 集群与线程池
  logback-spring.xml               # 日志
```

关键配置项：
- spring.batch.job.enabled：是否随应用启动自动运行 Job。
- index.jobs.full.cron / index.jobs.incremental.cron：调度表达式。
- index.parallelism.chunkSize / threads / partitions：并发与分片参数。
- index.retry.backoff.initial / max / attempts：重试参数。
- index.check.thresholds：完整性阈值。

## 约定与命名

- 包命名：`com.company.index` 为根包；按层次划分 `api/batch/scheduler/...`。
- Job/Step 命名：`FullIndexJob`, `IncrementalIndexJob`, `ReadProcessWriteStep` 等见名知义。
- Reader/Writer：实现接口并以数据源/目标命名，如 `RdbFullReader`, `ElasticsearchWriter`。

## 里程碑落地顺序（建议）

1) 最小可用路径：增量 Job + RDB→ES 流程 + 完整性检查 + Quartz 单机
2) 扩容：多线程 + 本地分片
3) 高可用：Quartz 集群 / K8s CronJob + 分布式锁
4) 远程分片与弹性：主控-工作器拓扑、多实例水平扩展
